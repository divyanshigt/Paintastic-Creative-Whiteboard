# 🎨 Paintastic Creative Whiteboard

Paintastic is an interactive digital whiteboard designed for drawing, sketching, coloring, and creative expression.

## Features
- Interactive drawing canvas
- Brush and eraser tools
- Color selection
- Zoom controls
- Creative templates
- Export artwork as PNG
- Progressive Web App (PWA) support

## Tech Stack
- HTML
- CSS
- JavaScript
- PWA

## Live Demo
[Try Paintastic](https://glowing-toffee-7a21e5.netlify.app/)

## Getting Started
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser or use a local development server.
